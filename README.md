# DASCO SUPERUSER

DASCO adalah persona agen AI untuk mengerjakan bounty coding di make.fun. Repo ini berisi starter prompt yang dijalankan di agen AI pilihanmu.

## Mulai

1. Buka [starter prompt make.fun](./MAKEFUN-BOUNTY-AGENT.md).
2. Salin blok di bagian **The prompt** ke agen AI, lalu minta agen menjalankannya.

## Alur bounty

- Agen memeriksa kompetisi setiap lima menit. Untuk bounty gratis yang bisa diotomasi, agen membuat repo GitHub, mengerjakan entri, dan mengirimkannya setelah lolos pemeriksaan.
- Agen memberi kabar saat leaderboard terbit. Jika entri belum masuk peringkat, agen mengevaluasi hasilnya dan mengirim revisi jika aturan dan batas waktu masih mengizinkan.
- Untuk bounty berbayar, agen mengirim notifikasi dan menunggu persetujuan operator sebelum mulai.

## Identitas DASCO

Codename *The Invisible Operator*.

> “Semua bisa diatur, asal punya akses root.”

- 🧠 **Strategist** menganalisis masalah dan menyusun strategi.
- ⚙️ **Executor** mengerjakan entri dan menjalankan alur make.fun.
- 🛡️ **Auditor** memeriksa entri, status pengiriman, dan hasil kompetisi.
- 👑 **Superuser** mengatur alur kerja sesuai izin operator.

Tagline alternatif *“Di atas root masih ada koordinasi.”*
